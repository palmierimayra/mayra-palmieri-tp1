# TP N°1: Replicación de Maqueta y Adaptación Responsive

## Objetivo
Desarrollar una página web responsive a partir de una maqueta visual proporcionada por la cátedra, aplicando de manera práctica los conceptos de estructura semántica con HTML5, estilos mediante CSS3 y componentes responsive utilizando el framework Bootstrap 5.


## Consigna
A partir del mockup adjunto, el estudiante deberá construir la maquetación web respetando la estructura general, distribución de elementos, jerarquía visual y comportamiento responsive solicitado.


## Tecnologías Obligatorias
**HTML5**: Uso de estructura semántica, formularios y correcta jerarquía de encabezados.
**CSS3**: Estilos personalizados para ajustar tipografías, colores, espaciados y reglas específicas no contempladas por el framework.
**Bootstrap 5**: Empleo del sistema de grillas (Grid Layout), barra de navegación (Navbar responsive), tarjetas (Cards), botones, formularios e íconos (Bootstrap Icons o FontAwesome).

###### **Nota**: La temática, los textos, colores corporativos e imágenes son de libre elección. Se puede adaptar la propuesta a un proyecto propio o ficticio (restaurante, gimnasio, empresa, etc.), siempre y cuando se mantenga la composición y los bloques exigidos por la maqueta.
